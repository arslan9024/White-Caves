Chapter 1: The Grand Architecture

Curated by @Aurora, Principal Systems CTO

Core Architectural Law: Clean Monolith Topology with unified execution paths across Next.js 15 App Router, Vite Single-Page Application engine, and distributed Node Express micro-services.

1. Hybrid Dual-Runtime Paradigm

White Caves operates with a dual frontend runtime:

  • Vite SPA Engine (npm run dev:client): Ultra-fast developer feedback and low-latency client dashboard render cycles.
  • Next.js 15 App Router (app/): Server-side rendering (SSR), high-performance Edge routing, and canonical DLD/Ejari compliance APIs.

2. Canonical State & Path Cleanliness

All system architectures, run logs, and business documents are encapsulated strictly inside .agents/ under TURING-ROOT-007.

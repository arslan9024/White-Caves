## Aegis V4.1 Governance

1. **Single Purpose File Law:** All files < 350 lines, single responsibility.
2. **5-Way File Standard:** View (`.view.tsx`), Logic (`.logic.ts`), Styles (`.styles.ts`), Data (`.data.ts`), Config (`.config.ts`).
3. **Continuous Deduplication:** Zero duplicate handlers or ghost directories.
4. **Zero-Backlog Law:** All PRs resolved, immediate merge verification.
5. **Token Preservation Shield:** Hard 15,000 token ceiling per task.

## 1. Revenue Stream Architecture

### Tier 1 — Transaction Revenue (Primary)

#### 1.1 Sales Commissions

| Transaction Type              | Commission Rate        | Notes                    |
| ----------------------------- | ---------------------- | ------------------------ |
| Off-plan new sale (developer) | 5–7% of property price | Developer pays 100%      |
| Off-plan secondary market     | 2% of transaction      | Split buyer/seller       |
| Ready property (primary)      | 2%                     | Buyer side               |
| Ready property (secondary)    | 1–2%                   | Both sides if dual agent |
| Commercial sale               | 2–3%                   | Negotiated               |
| Land sale                     | 1.5–2%                 | Per agreement            |

**DLD Transfer Fee Responsibility (Client):**

- 4% of property price (buyer pays)
- AED 4,000 admin fee

#### 1.2 Rental Commissions

| Type                    | Rate                 | Paid By  | Frequency                 |
| ----------------------- | -------------------- | -------- | ------------------------- |
| New residential lease   | 5% of annual rent    | Landlord | One-time on new lease     |
| New commercial lease    | 8–10% of annual rent | Landlord | One-time on new lease     |
| Lease renewal (managed) | 2% of annual rent    | Landlord | Per renewal               |
| Short-term rental setup | 10% of first month   | Landlord | Per booking channel setup |

## 8. Break-Even Analysis

### Fixed Cost Base (Monthly, Base Scenario)

| Category                                  | Monthly (AED) |
| ----------------------------------------- | ------------: |
| Office rent (Dubai office)                |        25,000 |
| Staff salaries (15 agents + 5 admin)      |       220,000 |
| Technology (CRM, portals, cloud)          |        15,000 |
| Marketing (portals + digital)             |        60,000 |
| Legal & compliance (RERA fees, insurance) |        12,000 |
| Miscellaneous                             |         8,000 |
| **Total Monthly Fixed Costs**             |   **340,000** |

### Break-Even Volume

```
Average contribution margin per sales transaction: AED 40,000 (after agent split)
Average contribution margin per managed unit/month: AED 364

Break-even (sales-only model): 340,000 / 40,000 = 8.5 transactions/month
Break-even (blended model, Y1 base):
  Property management contribution: 150 units × AED 364 = AED 54,600/mo
  Remaining gap: AED 340,000 − AED 54,600 = AED 285,400
  Sales transactions needed: AED 285,400 / AED 40,000 = 7.1 transactions/month
  → Break-even at ~8 sales transactions/month (achievable by month 4, base scenario)
```

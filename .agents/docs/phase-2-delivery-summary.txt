## 🚀 How to Get Started

### 1️⃣ Start the API Server
```bash
# Option A: Standalone (port 4000)
node test-relational-sidebar-standalone.js

# Option B: Main server (port 3000)
npm run server
```

### 2️⃣ Test the API
```bash
# Automated tests
node run-api-tests.js

# Manual testing
curl http://localhost:3000/api/relational-sidebar/departments
```

### 3️⃣ Integrate with Frontend
```javascript
// Use the API in Redux thunks
import { relationalSidebarAPI } from '../services/relationalSidebarAPI';

const departments = await relationalSidebarAPI.getDepartments();
```

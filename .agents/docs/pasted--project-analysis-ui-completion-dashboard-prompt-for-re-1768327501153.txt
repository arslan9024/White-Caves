# **PROJECT ANALYSIS & UI COMPLETION DASHBOARD**

## **PROMPT FOR REPLIT/AURORA PROJECT ANALYSIS**

```
Create a comprehensive project analysis and UI completion tracking system for the White Caves Real Estate AI Platform that:

1. **PROJECT SCANNER**: Automatically scans the entire codebase to identify all UI components and their current implementation status
2. **ACTION COMPLETION TRACKER**: Analyzes each component to determine implemented vs. pending actions/features
3. **DYNAMIC PROGRESS VIEW**: Shows real-time completion status above the dashboard but below top navigation
4. **SMART COMPONENT ENHANCEMENT**: Automatically adds "Under Construction" screens for incomplete components
5. **FEATURE PRIORITIZATION**: Identifies critical path features needed for MVP

Required Analysis Dimensions:

1. **COMPONENT INVENTORY**:
   - Scan all React/Vue components in the project
   - Identify component hierarchy and relationships
   - Map components to SRS requirements/pillars
   - Track component dependencies

2. **ACTION ANALYSIS**:
   - List all event handlers in each component
   - Check if handlers have actual implementations
   - Identify placeholder/stub functions
   - Track API integrations (connected vs. mocked)

3. **FEATURE COMPLETION METRICS**:
   - Calculate percentage of implemented features per component
   - Identify "zombie components" (UI with zero functionality)
   - Track navigation/routing completeness
   - Measure data flow completeness

4. **AUTOMATIC ENHANCEMENT**:
   - Add "Feature Under Construction" screens
   - Implement placeholder functionality with clear messaging
   - Add progress indicators to incomplete components
   - Create component-specific todo lists

5. **DYNAMIC DASHBOARD VIEW**:
   - Real-time completion percentage display
   - Component-by-component breakdown
   - Click to see detailed component analysis
   - Filter by pillar/department/priority

Technical Requirements:

- Zero manual configuration needed
- Works with current React/Next.js structure
- Respects existing component architecture
- Non-intrusive (doesn't break working features)
- Provides actionable improvement suggestions
- Updates in real-time as code changes

Success Metrics:
- 100% component identification accuracy
- Real-time analysis updates
- Zero false positives for "complete" components
- Actionable improvement suggestions
- User-friendly progress visualization
```

// Automated Component Scanner
class ProjectComponentAnalyzer {
  constructor() {
    this.components = new Map();
    this.analysisResults = null;
    this.scanInterval = null;
  }

  async scanEntireProject() {
    console.log('🔍 Scanning project for UI components...');
    
    const scanResults = {
      timestamp: new Date().toISOString(),
      totalComponents: 0,
      analyzedComponents: 0,
      componentsByType: {},
      completionMetrics: {},
      issues: []
    };

    // 1. Scan for React components
    const reactComponents = await this.scanForReactComponents();
    scanResults.totalComponents += reactComponents.length;
    
    // 2. Analyze each component
    for (const component of reactComponents) {
      const analysis = await this.analyzeComponent(component);
      this.components.set(component.filePath, analysis);
      scanResults.analyzedComponents++;
      
      // Track by type
      const type = analysis.componentType;
      if (!scanResults.componentsByType[type]) {
        scanResults.componentsByType[type] = [];
      }
      scanResults.componentsByType[type].push(analysis);
    }

    // 3. Calculate completion metrics
    scanResults.completionMetrics = this.calculateCompletionMetrics();
    
    // 4. Identify critical issues
    scanResults.issues = this.identifyCriticalIssues();
    
    this.analysisResults = scanResults;
    return scanResults;
  }

  async scanForReactComponents() {
    // Walk through project directory structure
    const projectRoot = process.cwd();
    const components = [];
    
    // Find all .jsx, .tsx, .js files
    const files = await this.walkDirectory(projectRoot);
    
    for (const file of files) {
      if (this.isReactComponentFile(file)) {
        const componentInfo = await this.extractComponentInfo(file);
        if (componentInfo) {
          components.push(componentInfo);
        }
      }
    }
    
    return components;
  }

  async analyzeComponent(component) {
    const analysis = {
      name: component.name,
      filePath: component.filePath,
      componentType: this.determineComponentType(component),
      linesOfCode: component.linesOfCode,
      
      // Feature analysis
      features: {
        total: 0,
        implemented: 0,
        pending: 0,
        underConstruction: 0
      },
      
      // Action analysis
      actions: {
        total: 0,
        implemented: 0,
        placeholders: 0,
        mockData: false
      },
      
      // UI analysis
      uiElements: {
        total: 0,
        interactive: 0,
        static: 0
      },
      
      // API integration
      apiConnections: {
        total: 0,
        connected: 0,
        mocked: 0
      },
      
      // Navigation
      navigation: {
        internalLinks: 0,
        externalLinks: 0,
        brokenLinks: 0
      },
      
      // Status
      status: 'unknown',
      completionPercentage: 0,
      priority: 'medium',
      
      // Recommendations
      recommendations: [],
      immediateActions: []
    };
    
    // Read component source code
    const sourceCode = await this.readFile(component.filePath);
    
    // Analyze features
    analysis.features = this.analyzeFeatures(sourceCode, component);
    
    // Analyze actions/event handlers
    analysis.actions = this.analyzeActions(sourceCode);
    
    // Analyze UI elements
    analysis.uiElements = this.analyzeUIElements(sourceCode);
    
    // Check API connections
    analysis.apiConnections = this.analyzeAPIConnections(sourceCode);
    
    // Calculate completion percentage
    analysis.completionPercentage = this.calculateComponentCompletion(analysis);
    
    // Determine status
    analysis.status = this.determineComponentStatus(analysis);
    
    // Generate recommendations
    analysis.recommendations = this.generateRecommendations(analysis);
    analysis.immediateActions = this.getImmediateActions(analysis);
    
    return analysis;
  }

  analyzeActions(sourceCode) {
    const actions = {
      total: 0,
      implemented: 0,
      placeholders: 0,
      list: []
    };
    
    // Pattern matching for event handlers
    const handlerPatterns = [
      /onClick\s*=\s*{([^}]+)}/g,
      /onChange\s*=\s*{([^}]+)}/g,
      /onSubmit\s*=\s*{([^}]+)}/g,
      /onKeyDown\s*=\s*{([^}]+)}/g,
      /onMouseEnter\s*=\s*{([^}]+)}/g,
      /onMouseLeave\s*=\s*{([^}]+)}/g,
      /const\s+(\w+)\s*=\s*\([^)]*\)\s*=>\s*{[^}]*}/g,
      /function\s+(\w+)\s*\([^)]*\)\s*{[^}]*}/g
    ];
    
    for (const pattern of handlerPatterns) {
      const matches = sourceCode.match(pattern) || [];
      actions.total += matches.length;
      
      for (const match of matches) {
        const action = {
          name: this.extractHandlerName(match),
          type: this.extractHandlerType(match),
          implementation: this.analyzeHandlerImplementation(match)
        };
        
        actions.list.push(action);
        
        if (action.implementation.status === 'implemented') {
          actions.implemented++;
        } else if (action.implementation.status === 'placeholder') {
          actions.placeholders++;
        }
      }
    }
    
    return actions;
  }

  analyzeHandlerImplementation(handlerCode) {
    // Check if handler has real implementation
    const placeholderPatterns = [
      /console\.log/,
      /\/\/\s*TODO/,
      /\/\/\s*FIXME/,
      /\/\*\s*TODO/,
      /alert\(/,
      /\/\/\s*Placeholder/,
      /throw new Error\(["']Not implemented["']\)/,
      /return null/,
      /return false/
    ];
    
    const isPlaceholder = placeholderPatterns.some(pattern => 
      pattern.test(handlerCode)
    );
    
    const hasRealLogic = this.hasRealLogic(handlerCode);
    
    return {
      status: isPlaceholder ? 'placeholder' : 
              hasRealLogic ? 'implemented' : 'empty',
      isPlaceholder,
      hasRealLogic,
      linesOfCode: (handlerCode.match(/\n/g) || []).length + 1
    };
  }

  calculateComponentCompletion(analysis) {
    let totalPoints = 0;
    let earnedPoints = 0;
    
    // Feature completeness (40% weight)
    totalPoints += 40;
    earnedPoints += (analysis.features.implemented / Math.max(analysis.features.total, 1)) * 40;
    
    // Action completeness (30% weight)
    totalPoints += 30;
    earnedPoints += (analysis.actions.implemented / Math.max(analysis.actions.total, 1)) * 30;
    
    // API integration (20% weight)
    totalPoints += 20;
    earnedPoints += (analysis.apiConnections.connected / Math.max(analysis.apiConnections.total, 1)) * 20;
    
    // UI completeness (10% weight)
    totalPoints += 10;
    earnedPoints += (analysis.uiElements.interactive / Math.max(analysis.uiElements.total, 1)) * 10;
    
    return Math.round((earnedPoints / totalPoints) * 100);
  }

  determineComponentStatus(analysis) {
    if (analysis.completionPercentage >= 90) return 'complete';
    if (analysis.completionPercentage >= 50) return 'partial';
    if (analysis.completionPercentage >= 10) return 'under-construction';
    return 'empty';
  }

  generateRecommendations(analysis) {
    const recommendations = [];
    
    if (analysis.completionPercentage === 0) {
      recommendations.push({
        priority: 'high',
        action: 'Add basic functionality or mark as under construction',
        type: 'feature'
      });
    }
    
    if (analysis.actions.placeholders > 0) {
      recommendations.push({
        priority: 'medium',
        action: `Implement ${analysis.actions.placeholders} placeholder action(s)`,
        type: 'action'
      });
    }
    
    if (analysis.apiConnections.mocked > 0) {
      recommendations.push({
        priority: 'low',
        action: `Replace ${analysis.apiConnections.mocked} mock API calls with real endpoints`,
        type: 'api'
      });
    }
    
    return recommendations;
  }

  getImmediateActions(analysis) {
    const actions = [];
    
    if (analysis.status === 'empty') {
      actions.push({
        type: 'enhance',
        description: 'Add "Under Construction" screen',
        component: 'UnderConstructionOverlay'
      });
    }
    
    if (analysis.actions.placeholders > 0 && analysis.actions.implemented === 0) {
      actions.push({
        type: 'implement',
        description: 'Implement at least one action handler',
        component: 'ActionHandlerStarter'
      });
    }
    
    return actions;
  }

  calculateCompletionMetrics() {
    const components = Array.from(this.components.values());
    
    const metrics = {
      totalComponents: components.length,
      completedComponents: components.filter(c => c.status === 'complete').length,
      underConstruction: components.filter(c => c.status === 'under-construction').length,
      emptyComponents: components.filter(c => c.status === 'empty').length,
      
      averageCompletion: Math.round(
        components.reduce((sum, c) => sum + c.completionPercentage, 0) / 
        Math.max(components.length, 1)
      ),
      
      totalActions: components.reduce((sum, c) => sum + c.actions.total, 0),
      implementedActions: components.reduce((sum, c) => sum + c.actions.implemented, 0),
      placeholderActions: components.reduce((sum, c) => sum + c.actions.placeholders, 0),
      
      byPillar: this.groupByPillar(components),
      byDepartment: this.groupByDepartment(components)
    };
    
    return metrics;
  }

  identifyCriticalIssues() {
    const components = Array.from(this.components.values());
    const issues = [];
    
    // Find components with zero functionality
    const zombieComponents = components.filter(c => 
      c.actions.total === 0 && 
      c.uiElements.interactive === 0 &&
      c.completionPercentage === 0
    );
    
    if (zombieComponents.length > 0) {
      issues.push({
        type: 'zombie_components',
        severity: 'high',
        count: zombieComponents.length,
        components: zombieComponents.map(c => c.name),
        solution: 'Add basic functionality or remove component'
      });
    }
    
    // Find components with only placeholders
    const placeholderComponents = components.filter(c => 
      c.actions.placeholders > 0 && 
      c.actions.implemented === 0
    );
    
    if (placeholderComponents.length > 0) {
      issues.push({
        type: 'placeholder_components',
        severity: 'medium',
        count: placeholderComponents.length,
        components: placeholderComponents.map(c => c.name),
        solution: 'Replace placeholders with real implementations'
      });
    }
    
    return issues;
  }

  // Helper methods
  isReactComponentFile(filePath) {
    return /\.(jsx|tsx|js)$/.test(filePath) && 
           !filePath.includes('node_modules') &&
           !filePath.includes('.test.') &&
           !filePath.includes('.spec.');
  }

  async walkDirectory(dir) {
    // Implementation for directory walking
    const fs = require('fs').promises;
    const path = require('path');
    
    const files = [];
    
    async function walk(currentPath) {
      const items = await fs.readdir(currentPath, { withFileTypes: true });
      
      for (const item of items) {
        const fullPath = path.join(currentPath, item.name);
        
        if (item.isDirectory() && 
            !item.name.includes('node_modules') &&
            !item.name.startsWith('.') &&
            item.name !== 'build' &&
            item.name !== 'dist') {
          await walk(fullPath);
        } else if (item.isFile() && this.isReactComponentFile(fullPath)) {
          files.push(fullPath);
        }
      }
    }
    
    await walk(dir);
    return files;
  }
}

const CompletionDashboard = () => {

    }

// Component Card
const ComponentCard = ({ component, isSelected, onSelect, onAutoFix, onPrioritize }) => {
  const getStatusColor = (status) => {
    switch (status) {
      case 'complete': return '#10b981';
      case 'partial': return '#f59e0b';
      case 'under-construction': return '#6366f1';
      case 'empty': return '#ef4444';
      default: return '#6b7280';
    }
  };

  const getStatusIcon = (status) => {
    switch (status) {
      case 'complete': return 'icon-check-circle';
      case 'partial': return 'icon-alert-circle';
      case 'under-construction': return 'icon-construction';
      case 'empty': return 'icon-x-circle';
      default: return 'icon-help-circle';
    }
  };

  return (
    <div 
      className={`component-card status-${component.status} ${isSelected ? 'selected' : ''}`}
      onClick={onSelect}
    >
      <div className="card-header">
        <div className="component-name">
          <i className={getStatusIcon(component.status)}></i>
          <span>{component.name}</span>
        </div>
        <div className="component-actions">
          {component.status === 'empty' && (
            <button 
              className="btn-auto-fix"
              onClick={(e) => {
                e.stopPropagation();
                onAutoFix(component.name);
              }}
              title="Auto-add Under Construction overlay"
            >
              <i className="icon-magic"></i>
            </button>
          )}
          <button 
            className="btn-prioritize"
            onClick={(e) => {
              e.stopPropagation();
              onPrioritize(component.name);
            }}
            title="Mark as high priority"
          >
            <i className="icon-flag"></i>
          </button>
        </div>
      </div>
      
      <div className="card-content">
        <div className="completion-progress">
          <div className="progress-label">Completion</div>
          <div className="progress-bar">
            <div 
              className="progress-fill"
              style={{ 
                width: `${component.completionPercentage}%`,
                backgroundColor: getStatusColor(component.status)
              }}
            ></div>
          </div>
          <div className="progress-percentage">
            {component.completionPercentage}%
          </div>
        </div>
        
        <div className="component-metrics">
          <div className="metric">
            <span className="metric-value">{component.actions.implemented}/{component.actions.total}</span>
            <span className="metric-label">Actions</span>
          </div>
          <div className="metric">
            <span className="metric-value">{component.features.implemented}/{component.features.total}</span>
            <span className="metric-label">Features</span>
          </div>
          <div className="metric">
            <span className="metric-value">{component.apiConnections.connected}/{component.apiConnections.total}</span>
            <span className="metric-label">APIs</span>
          </div>
        </div>
        
        {component.actions.placeholders > 0 && (
          <div className="placeholder-warning">
            <i className="icon-warning"></i>
            {component.actions.placeholders} placeholder action(s)
          </div>
        )}
      </div>
      
      <div className="card-footer">
        <span className="file-path">{component.filePath}</span>
        <span className="priority-badge priority-{component.priority}">
          {component.priority}
        </span>
      </div>
    </div>
  );
};

// Automated Under Construction Overlay System
class UnderConstructionEnhancer {
  constructor() {
    this.overlayTemplate = this.getOverlayTemplate();
    this.stubGenerator = new ActionStubGenerator();
  }

  async addOverlayToComponent(componentName, componentPath) {
    const componentCode = await this.readComponent(componentPath);
    
    // Check if component already has overlay
    if (this.hasUnderConstructionOverlay(componentCode)) {
      console.log(`Component ${componentName} already has under construction overlay`);
      return false;
    }
    
    // Generate enhanced component with overlay
    const enhancedCode = this.injectOverlay(componentCode, componentName);
    
    // Backup original
    await this.backupComponent(componentPath);
    
    // Write enhanced component
    await this.writeComponent(componentPath, enhancedCode);
    
    return true;
  }

  injectOverlay(originalCode, componentName) {
    // Parse component to find render/return statement
    const lines = originalCode.split('\n');
    let injectionPoint = -1;
    
    // Find the main render return statement
    for (let i = 0; i < lines.length; i++) {
      if (lines[i].includes('return (') || 
          lines[i].includes('return(') ||
          (lines[i].includes('render()') && lines[i+1]?.includes('return'))) {
        injectionPoint = i + 1;
        break;
      }
    }
    
    if (injectionPoint === -1) {
      // If no return found, wrap entire component
      return this.wrapEntireComponent(originalCode, componentName);
    }
    
    // Inject overlay at the beginning of the return
    const overlayCode = this.generateOverlayCode(componentName);
    
    lines.splice(injectionPoint, 0, overlayCode);
    
    // Add necessary imports
    const importStatement = `import UnderConstructionOverlay from '../components/common/UnderConstructionOverlay';`;
    if (!originalCode.includes('UnderConstructionOverlay')) {
      lines.unshift(importStatement);
    }
    
    return lines.join('\n');
  }

  wrapEntireComponent(originalCode, componentName) {
    // For functional components without explicit return
    const overlayCode = `
  return (
    <UnderConstructionOverlay 
      componentName="${componentName}"
      expectedCompletion="2 weeks"
      contactPerson="Development Team"
    >
      ${originalCode}
    </UnderConstructionOverlay>
  );
`;
    
    // Find the component function end
    const lines = originalCode.split('\n');
    const lastLine = lines[lines.length - 1];
    
    if (lastLine.trim() === '}') {
      lines[lines.length - 1] = overlayCode;
      lines.push('}');
    }
    
    // Add import
    if (!originalCode.includes('UnderConstructionOverlay')) {
      lines.unshift(`import UnderConstructionOverlay from '../components/common/UnderConstructionOverlay';`);
    }
    
    return lines.join('\n');
  }

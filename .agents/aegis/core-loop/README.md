# Turing Orchestrator Core Loop

## Overview
This directory contains the **Turing Orchestrator** implementation – a high‑performance, credit‑budget‑aware engine that evaluates plans, applies policies, and manages workflow execution.

It satisfies **AEG‑001 – AEG‑042** and adheres to **TURING‑LAW‑000** (parallel tool batching, line limits, zero‑token scripts).

## Getting Started
```bash
# Install dependencies (if not already installed)
npm ci

# Run the orchestrator (starts metrics server on $TURING_ORCHESTRATOR_PORT or 3000)
node runOrchestrator.ts
```

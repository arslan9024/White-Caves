Here's a comprehensive prompt for Replit agent to fix Vercel deployment issues and optimize the deployment:

---

**Prompt for Replit Agent:**

I'm having Vercel deployment errors with my project. Please help me:

1. **First, diagnose my current setup:**
   - Check my `package.json` for build scripts and dependencies
   - Examine any framework configuration files (Next.js, React, Vue, etc.)
   - Look for `vercel.json`, `next.config.js`, or similar deployment configs

2. **Fix common Vercel deployment issues:**
   - Ensure Node.js version is specified in `package.json` (add `"engines": {"node": "18.x"}` if missing)
   - Verify build command is correct for my framework
   - Check if output directory is properly configured
   - Ensure environment variables are properly set up

3. **Add/optimize deployment configuration:**
   - Create/update `vercel.json` with:
     ```json
     {
       "builds": [
         {
           "src": "package.json",
           "use": "@vercel/static-build",
           "config": { "distDir": "build" }
         }
       ],
       "routes": [
         {
           "handle": "filesystem"
         },
         {
           "src": "/(.*)",
           "dest": "/index.html"
         }
       ]
     }
     ```
   - Adjust `distDir` based on my framework (build, out, dist, etc.)

4. **Optimize build process:**
   - Add proper build script in `package.json`
   - Install necessary dev dependencies if missing
   - Add build caching configuration if applicable
   - Configure proper ignore patterns in `.vercelignore`

5. **Add troubleshooting steps:**
   - Include a deployment health check
   - Add error logging for build failures
   - Set up proper redirects and headers

6. **If using a specific framework, apply framework-specific optimizations:**
   - **Next.js:** Ensure `next.config.js` is properly configured
   - **React/Vite:** Check base path and asset optimization
   - **Node.js/Express:** Configure serverless functions properly

7. **Create a deployment checklist** in a `DEPLOYMENT.md` file with:
   - Environment variables needed
   - Build command steps
   - Common error solutions
   - Rollback instructions

---

**Additional context to include with the prompt:**
- Share your specific error messages from Vercel logs
- Mention your framework (Next.js, React, Vue, Node.js, etc.)
- Note if you're using TypeScript or any special configurations
- Specify if this is a frontend-only or fullstack application

This prompt will guide the Replit agent to systematically fix deployment issues while upgrading your codebase for better build reliability.

🏢 White Caves Real Estate API

Version: 1.0.0

Description: Complete REST API for the White Caves real estate platform featuring AI-powered chatbot, intelligent agent matching, real-time notifications, and comprehensive analytics.

Base URL: http://localhost:5000/api (Development) | https://api.whitecaves.com (Production)

Documentation: Use the interactive Swagger UI below to explore and test all endpoints.

POST

Process Message

/chatbot/message

Send a message to the AI chatbot and receive property recommendations

GET

Conversation History

/chatbot/conversations/{id}/history

Retrieve the complete history of a conversation

POST

Score Lead Quality

/chatbot/conversations/{id}/score-lead

Calculate lead quality score based on conversation

POST

Assign Agent

/agents/assign

Find and assign the best-matching agent for a lead

GET

Get Agent Details

/agents/{agentId}

Retrieve detailed information about a specific agent

POST

Send Notification

/notifications/send

Send notification via email, SMS, or push

GET

User Notifications

/notifications/user/{userId}

Retrieve notification history for a user

GET

Dashboard Data

/dashboard/data

Get comprehensive dashboard metrics and analytics

GET

Market Analytics

/dashboard/analytics

Retrieve market trends and property statistics

GET

Health Check

/health

Check API server health status

## ⚠️ IF SOMETHING GOES WRONG

### Most Common Issues & Fixes

**Issue**: "Vercel command not found"
**Fix**: `npm install -g vercel`

**Issue**: "Build failed"
**Fix**: `npm run build` (rebuild locally first)

**Issue**: "URL shows blank page"
**Fix**: Wait 30 sec, refresh (Ctrl+Shift+R)

**Issue**: "Want to rollback"
**Fix**: Vercel dashboard → Promotions → Previous version

**Detailed troubleshooting**: See VERCEL_DEPLOYMENT_GUIDE.md

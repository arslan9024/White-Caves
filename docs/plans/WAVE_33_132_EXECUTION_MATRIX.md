## 3. Mandatory per-wave packet

Every wave must declare:

1. wave ID
2. owner department + sub-department
3. goal statement
4. in-scope artifacts
5. out-of-scope guardrails
6. prerequisites
7. dependency links
8. quantified acceptance criteria
9. validation steps
10. quality gates
11. rollback path
12. blocker escalation policy
13. KPI target delta
14. reporting template
15. FEEDS/CONSUMES/FEEDS_ACK entries

## 4. Cadence

- 3 build waves + 1 stabilization wave.
- calibration review every 8 waves.
- strategic reset every 20 waves.

## 5. Quality control

A wave cannot close when:

- mandatory packet is incomplete,
- acceptance criteria are non-quantified,
- validation evidence is missing,
- tracker synchronization is missing.

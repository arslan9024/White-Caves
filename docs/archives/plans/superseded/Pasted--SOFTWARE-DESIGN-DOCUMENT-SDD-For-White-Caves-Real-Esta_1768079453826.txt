## **1. SYSTEM ARCHITECTURE OVERVIEW** *(UPDATED)*

### **1.1 Architectural Pattern**
**Event-Driven Microservices with Property-Centric Design** featuring:
- **Domain-Driven Design**: Property management as first-class domain
- **CQRS Pattern**: Separate read/write models for property inventory
- **Event Sourcing**: Complete audit trail of property lifecycle events
- **API Gateway Aggregation**: Property data aggregation across services

#### **2.2.1 Component Responsibilities**

```typescript
class PropertyValuationService {
  private valuationEngine: ValuationEngine;
  private marketDataService: MarketDataService;
  private aiModelService: AIModelService;
  
  calculateValuation(propertyId: string, method: ValuationMethod): ValuationResult;
  getComparativeMarketAnalysis(propertyId: string): CMAReport;
  calculateRentalYield(propertyId: string): YieldAnalysis;
  assessInvestmentPotential(propertyId: string): InvestmentScore;
  generateValuationReport(propertyId: string): ValuationReport;
  updateMarketData(community: string, data: MarketData): void;
}

class ValuationEngine {
  private cmamethod: CMAValuation;
  private incomeMethod: IncomeApproach;
  private costMethod: ReplacementCost;
  
  executeValuation(property: Property, method: ValuationMethod): ValuationResult {
    switch(method) {
      case 'CMA':
        return this.cmaMethod.calculate(property);
      case 'INCOME':
        return this.incomeMethod.calculate(property);
      case 'COST':
        return this.costMethod.calculate(property);
      case 'AUTO':
        return this.calculateAutoValuation(property);
    }
  }
  
  private calculateAutoValuation(property: Property): ValuationResult {
    // Weighted average of all methods
    const cma = this.cmaMethod.calculate(property);
    const income = this.incomeMethod.calculate(property);
    const cost = this.costMethod.calculate(property);
    
    return {
      value: (cma.value * 0.5) + (income.value * 0.3) + (cost.value * 0.2),
      confidence: this.calculateConfidence([cma, income, cost]),
      breakdown: { cma, income, cost },
      timestamp: new Date()
    };
  }
}

class CMAValuation {
  calculate(property: Property): ValuationResult {
    // Find comparable properties
    const comparables = this.findComparables(property);
    
    // Adjust for differences
    const adjustedValues = comparables.map(comp => 
      this.adjustForDifferences(comp, property)
    );
    
    // Calculate weighted average
    const value = this.calculateWeightedAverage(adjustedValues);
    
    return {
      value,
      comparables: comparables.map((comp, i) => ({
        propertyId: comp.propertyId,
        salePrice: comp.salePrice,
        adjustedValue: adjustedValues[i],
        similarityScore: this.calculateSimilarity(comp, property)
      })),
      adjustments: this.getAdjustmentDetails(property, comparables)
    };
  }
  
  private findComparables(property: Property): ComparableProperty[] {
    // Spatial search within 1km
    // Same property type and size (±20%)
    // Recent sales (last 6 months)
    // Similar amenities and condition
    return this.propertySearch.findSimilarProperties(property);
  }
}
```

```typescript
class SyndicationEngine {
  private channels: Map<string, ChannelAdapter>;
  
  async syndicate(listing: Listing, channels: Channel[]): Promise<SyndicationResult[]> {
    const results = await Promise.allSettled(
      channels.map(channel => this.syndicateToChannel(listing, channel))
    );
    
    return results.map((result, index) => ({
      channel: channels[index],
      success: result.status === 'fulfilled',
      externalId: result.status === 'fulfilled' ? result.value : null,
      error: result.status === 'rejected' ? result.reason : null
    }));
  }
  
  private async syndicateToChannel(listing: Listing, channel: Channel): Promise<string> {
    const adapter = this.channels.get(channel.id);
    if (!adapter) throw new Error(`No adapter for channel: ${channel.id}`);
    
    // Transform listing to channel-specific format
    const channelListing = adapter.transformListing(listing);
    
    // Upload media assets
    const mediaUrls = await adapter.uploadMedia(listing.media);
    
    // Create listing on external platform
    const externalId = await adapter.createListing(channelListing, mediaUrls);
    
    // Schedule sync updates
    this.scheduleSync(listing.id, channel.id, externalId);
    
    return externalId;
  }
}

class MarketingPackage {
  packageId: string;
  name: string; // Basic, Premium, Luxury, Platinum
  description: string;
  channels: Channel[];
  includedServices: Service[];
  contentRequirements: ContentRequirements;
  pricing: PackagePricing;
  duration: number; // Days
  performanceGuarantees: PerformanceGuarantee[];
  
  validateForProperty(property: Property): ValidationResult {
    // Check if property meets package requirements
    if (property.classification.priceTier < this.minimumTier) {
      return { valid: false, reason: 'property_tier_too_low' };
    }
    
    if (!this.meetsMediaRequirements(property.media)) {
      return { valid: false, reason: 'media_requirements_not_met' };
    }
    
    return { valid: true };
  }
}
```

```typescript
class Portfolio {
  portfolioId: string;
  ownerId: string;
  name: string;
  objective: PortfolioObjective; // Income, Growth, Balanced
  properties: PortfolioProperty[];
  performance: PortfolioPerformance;
  allocations: PortfolioAllocations;
  riskProfile: RiskProfile;
  benchmarks: Benchmark[];
  history: PortfolioHistory[];
  
  calculatePerformance(): PortfolioPerformance {
    return {
      totalValue: this.calculateTotalValue(),
      totalCost: this.calculateTotalCost(),
      unrealizedGainLoss: this.calculateUnrealizedGainLoss(),
      annualizedReturn: this.calculateAnnualizedReturn(),
      cashFlow: this.calculateCashFlow(),
      occupancyRate: this.calculateOccupancyRate(),
      diversificationScore: this.calculateDiversificationScore()
    };
  }
  
  calculateDiversificationScore(): number {
    // Calculate diversification across:
    // 1. Property types (25% weight)
    // 2. Geographic locations (25% weight)
    // 3. Price tiers (20% weight)
    // 4. Market segments (15% weight)
    // 5. Investment duration (15% weight)
    
    return this.calculateWeightedScore([
      this.diversifyByPropertyType(),
      this.diversifyByGeography(),
      this.diversifyByPriceTier(),
      this.diversifyByMarketSegment(),
      this.diversifyByInvestmentDuration()
    ]);
  }
}

class PortfolioAnalytics {
  analyzePortfolio(portfolio: Portfolio): PortfolioAnalysis {
    return {
      performance: portfolio.calculatePerformance(),
      risk: this.assessRisk(portfolio),
      diversification: this.analyzeDiversification(portfolio),
      liquidity: this.analyzeLiquidity(portfolio),
      taxEfficiency: this.analyzeTaxEfficiency(portfolio),
      recommendations: this.generateRecommendations(portfolio)
    };
  }
  
  private assessRisk(portfolio: Portfolio): RiskAssessment {
    return {
      marketRisk: this.calculateMarketRisk(portfolio),
      concentrationRisk: this.calculateConcentrationRisk(portfolio),
      liquidityRisk: this.calculateLiquidityRisk(portfolio),
      regulatoryRisk: this.calculateRegulatoryRisk(portfolio),
      overallRiskScore: this.calculateOverallRiskScore(portfolio)
    };
  }
```

#### **5.1.1 Property Access Control Matrix**
```typescript
class PropertyAccessControl {
  private permissionMatrix: Map<UserType, PropertyAccessLevel>;
  
  checkPropertyAccess(
    userId: string,
    propertyId: string,
    action: PropertyAction
  ): AccessResult {
    const user = await this.getUser(userId);
    const property = await this.getProperty(propertyId);
    
    // Check user type permissions
    const userPermissions = this.permissionMatrix.get(user.userType);
    if (!userPermissions.allowedActions.includes(action)) {
      return { allowed: false, reason: 'user_type_not_permitted' };
    }
    
    // Check property-specific restrictions
    if (property.restrictions.requiresUaePass && !user.uaePassVerified) {
      return { allowed: false, reason: 'uae_pass_required' };
    }
    
    // Check tier restrictions for premium properties
    if (property.classification.priceTier >= 'luxury' && user.tier < 'premium') {
      return { allowed: false, reason: 'insufficient_tier' };
    }
    
    // Check ownership/relationship
    if (action === 'edit' && !this.isOwnerOrAgent(userId, propertyId)) {
      return { allowed: false, reason: 'not_owner_or_agent' };
    }
    
    return { allowed: true };
  }
  
  private isOwnerOrAgent(userId: string, propertyId: string): boolean {
    const property = await this.getProperty(propertyId);
    
    // Check if user is owner
    if (property.ownership.ownerId === userId) return true;
    
    // Check if user is assigned agent
    if (property.marketing.assignedAgents.includes(userId)) return true;
    
    // Check department access for internal staff
    const user = await this.getUser(userId);
    if (user.userType === 'internal_staff') {
      const department = user.department;
      const allowedDepartments = ['sales', 'property_management', 'operations'];
      return allowedDepartments.includes(department);
    }
    
    return false;
  }
}
```

```typescript
class PropertyDataEncryption {
  private encryptionService: EncryptionService;
  
  async encryptPropertyData(property: Property): Promise<EncryptedProperty> {
    return {
      propertyId: property.propertyId,
      // Public data (stored in plain text)
      basicInfo: property.basicInfo,
      classification: property.classification,
      
      // Sensitive data (encrypted)
      ownership: await this.encryptionService.encrypt(
        JSON.stringify(property.ownership),
        { keyId: 'property_ownership_key', classification: 'PII' }
      ),
      
      financials: await this.encryptionService.encrypt(
        JSON.stringify(property.pricing),
        { keyId: 'property_financials_key', classification: 'FINANCIAL' }
      ),
      
      documents: await Promise.all(
        property.documents.map(doc => 
          this.encryptionService.encryptDocument(doc)
        )
      )
    };
  }
  
  async decryptForUser(
    encryptedProperty: EncryptedProperty,
    userId: string
  ): Promise<Partial<Property>> {
    const user = await this.getUser(userId);
    const decrypted: Partial<Property> = {
      propertyId: encryptedProperty.propertyId,
      basicInfo: encryptedProperty.basicInfo,
      classification: encryptedProperty.classification
    };
    
    // Decrypt ownership if user is owner/agent
    if (this.canAccessOwnership(user, encryptedProperty.propertyId)) {
      decrypted.ownership = await this.encryptionService.decrypt(
        encryptedProperty.ownership
      );
    }
    
    // Decrypt financials if user has financial access
    if (this.canAccessFinancials(user)) {
      decrypted.pricing = await this.encryptionService.decrypt(
        encryptedProperty.financials
      );
    }
    
    return decrypted;
  }
}
```

```typescript
      propertyDetails: response.data.propertyDetails,
      restrictions: response.data.restrictions,
      lastUpdated: response.data.lastUpdated
    };
    
    // Cache for 24 hours
    await this.cache.set(
      `title_verification:${propertyDetails.titleDeedNumber}`,
```

```typescript
    const listing = await this.getListing(listingId);
    const results = [];
    
    for (const channel of channels) {
      const adapter = this.adapters.get(channel);
      if (!adapter) {
        results.push({ channel, success: false, error: 'Adapter not found' });
        continue;
      }
      
      try {
        const transformed = await adapter.transformListing(listing);
        const media = await adapter.uploadMedia(listing.media);
        const externalId = await adapter.createListing(transformed, media);
        
        results.push({
          channel,
          success: true,
          externalId,
          url: this.generatePortalUrl(channel, externalId)
        });
        
        // Store syndication record
        await this.storeSyndicationRecord(listingId, channel, externalId);
        
      } catch (error) {
        results.push({
          channel,
          success: false,
          error: error.message
        });
      }
    }
    
    return results;
  }
```

### **10.2 Property Transaction Recovery**

#### **10.2.1 Transaction Journaling**
```typescript
class PropertyTransactionRecovery {
  private transactionJournal: TransactionJournal;
  private recoveryManager: RecoveryManager;
  
  async executePropertyTransaction(
    transaction: PropertyTransaction
  ): Promise<TransactionResult> {
    // Start transaction in journal
    const journalEntry = await this.transactionJournal.start(
      transaction.id,
      transaction.type,
      transaction.participants,
      transaction.amount
    );
    
    try {
      // Step 1: Reserve funds
      await this.reserveFunds(transaction);
      await this.transactionJournal.stepCompleted(journalEntry.id, 'funds_reserved');
      
      // Step 2: Verify documents
      await this.verifyDocuments(transaction.documents);
      await this.transactionJournal.stepCompleted(journalEntry.id, 'documents_verified');
      
      // Step 3: Submit to DLD
      const dldResult = await this.submitToDLD(transaction);
      await this.transactionJournal.stepCompleted(journalEntry.id, 'dld_submitted');
      
      // Step 4: Transfer funds
      await this.transferFunds(transaction);
      await this.transactionJournal.stepCompleted(journalEntry.id, 'funds_transferred');
      
      // Step 5: Update ownership
      await this.updateOwnership(transaction.propertyId, transaction.buyerId);
      await this.transactionJournal.stepCompleted(journalEntry.id, 'ownership_updated');
      
      // Complete transaction
      await this.transactionJournal.complete(journalEntry.id, 'success');
      
      return { success: true, dldReference: dldResult.reference };
      
    } catch (error) {
      // Log failure
      await this.transactionJournal.fail(journalEntry.id, error.message);
      
      // Attempt recovery based on last completed step
      await this.recoverTransaction(journalEntry.id);
      
      throw error;
    }
  }
  
  private async recoverTransaction(journalEntryId: string): Promise<void> {
    const journalEntry = await this.transactionJournal.get(journalEntryId);
    
    switch (journalEntry.lastCompletedStep) {
      case 'funds_reserved':
        // Release reserved funds
        await this.releaseFunds(journalEntry.transactionId);
        break;
        
      case 'dld_submitted':
        // Cancel DLD submission if possible
        await this.cancelDLDSubmission(journalEntry.transactionId);
        await this.releaseFunds(journalEntry.transactionId);
        break;
        
      case 'funds_transferred':
        // This is complex - may require manual intervention
        await this.escalateRecovery(journalEntry);
        break;
    }
  }
}
```

## **APPENDIX: TECHNICAL DECISIONS LOG** *(UPDATED)*

### **Decision 6: Elasticsearch for Property Search**
**Decision**: Use Elasticsearch as primary property search engine
**Rationale**:
- Superior full-text search capabilities for property descriptions
- Advanced geospatial search for location-based queries
- Faceted filtering for property attributes (bedrooms, price range, amenities)
- Real-time indexing for new property listings
- Scalable distributed architecture

### **Decision 7: TimescaleDB for Market Data**
**Decision**: Use TimescaleDB for time-series market data
**Rationale**:
- Optimized for time-series data (price trends, market metrics)
- Continuous aggregates for real-time analytics
- Efficient compression for historical data
- SQL interface with time-series extensions
- Integration with Grafana for dashboards

### **Decision 8: PostGIS for Spatial Operations**
**Decision**: Use PostGIS for advanced geospatial queries
**Rationale**:
- Standard SQL interface with spatial extensions
- Advanced spatial operations (distance, containment, intersection)
- Integration with mapping services (Mapbox, Google Maps)
- Support for complex geometries (polygons for communities)
- Mature ecosystem with good tooling

### **Decision 9: Multi-CDN Strategy for Media**
**Decision**: Implement multi-CDN for property media delivery
**Rationale**:
- Improved global access to property images/videos
- Redundancy in case of CDN failure
- Geographic optimization for international clients
- Better performance for virtual tours
- Cost optimization across regions

### **Decision 10: Event Sourcing for Property History**
**Decision**: Implement event sourcing for property lifecycle
**Rationale**:
- Complete audit trail of all property changes
- Ability to reconstruct property state at any point in time
- Support for complex business rules and validations
- Foundation for analytics and reporting
- Better debugging and compliance tracking

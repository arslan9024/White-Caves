## 2. Common operating card schema (for all 108 sub-departments)

Each unit must define:

- Unit ID
- Mission
- Owner/Deputy
- Inbound dependencies
- Outbound deliverables
- SLA (target + breach threshold)
- Escalation ladder
- KPI formula set
- Evidence artifacts
- Top 10 failure modes + mitigations

## 1) Documentation architecture overview

The repository now uses a layered documentation model:

- **Business documentation** — business rules, operating model, compliance expectations, and feature intent.
- **Software documentation** — software requirements, design contracts, governance, and delivery readiness.
- **Planning and governance** — implementation waves, progress tracking, and traceability into execution.

The documentation system now includes:

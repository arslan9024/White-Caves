## 9. Win/Loss Analysis Framework

### 9.1 Mandatory CRM Fields for Every WON/LOST Lead

> Every time a lead reaches WON or LOST status, the agent MUST complete these fields before the status is saved. The CRM form will block saving without completion.

**For WON deals:**

| Field                        | Type                    | Required    | Options                                                                                                                |
| ---------------------------- | ----------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------- |
| `win_primary_reason`         | Dropdown                | ✅          | Service quality / Niche expertise / Price / Compliance / Referral / WhatsApp responsiveness / Portal quality / Other   |
| `was_competitor_involved`    | Boolean                 | ✅          | Yes / No                                                                                                               |
| `competitor_who_lost_to_us`  | Dropdown (if yes above) | Conditional | Bayut agent / PropertyFinder agent / Allsopp / Betterhomes / Espace / Direct developer / Other agency / Not applicable |
| `client_key_decision_factor` | Free text               | ✅          | What the client said mattered most                                                                                     |
| `deal_cycle_days`            | Auto-calculated         | ✅          | lead.wonAt − lead.createdAt                                                                                            |

**For LOST deals:**

| Field                             | Type      | Required     | Options                                                                                                                                                             |
| --------------------------------- | --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `loss_primary_reason`             | Dropdown  | ✅           | Price (commission) / Service perception / Language barrier / Competitor won / Client changed mind / Budget changed / Timing / Trust / Property not suitable / Other |
| `competitor_who_won`              | Dropdown  | ✅           | Bayut agent / PropertyFinder agent / Allsopp / Betterhomes / Espace / Direct developer / Other agency / Unknown / No competitor (client not buying)                 |
| `could_have_been_saved`           | Boolean   | ✅           | Yes / No                                                                                                                                                            |
| `what_would_have_changed_outcome` | Free text | If saved=Yes | Agent's honest assessment                                                                                                                                           |
| `client_final_feedback`           | Free text | Optional     | What client said when they went elsewhere                                                                                                                           |

### 9.2 Monthly Win/Loss Review Process

**Meeting:** Last Friday of every month | 30 min | Sales Manager + MD

**Agenda:**

1. Win/Loss ratio for the month (target: ≥ 60% win rate on BANT-qualified leads)
2. Top 3 win reasons — what are we doing right? Amplify.
3. Top 3 loss reasons — what's the pattern? Action plan.
4. Competitor wins breakdown — who beat us, how often?
5. "Could have been saved" leads — what specific actions would have changed outcome?

**Output:** One-page Win/Loss Summary added to Monthly Sales Report (Section 14.2 above)

## 11. Price Sensitivity Analysis — DAMAC Hills 2 Market

### 11.1 Price Elasticity: When Do Buyers Switch Agents?

Based on qualitative research and industry benchmarks for Dubai real estate market (2024–2026):

| Commission Scenario                                     | Buyer Behavior                                                                          | Conversion Impact                     |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------- |
| Standard 2% (AED 40k on AED 2M deal)                    | Accepted as market standard — no pushback in > 85% of cases                             | Baseline                              |
| 2% + full service (DLD guidance, compliance, valuation) | Increased perceived value — clients less likely to negotiate down                       | +10–15% conversion vs fee-only agents |
| Agent requests > 2% (e.g., 2.5–3%)                      | Moderate resistance — 30–40% of clients will negotiate or shop around                   | -15% conversion                       |
| Agent offers < 2% (e.g., 1.5%)                          | Short-term win on price; risk of perceived low quality / desperation signal             | Avoid as opening offer                |
| Commission waiver (developer-paid only)                 | Off-plan transactions — client pays 0 directly; White Caves earns from developer (5–7%) | High volume, lower per-deal control   |

**Key Insight:** Dubai luxury real estate buyers are NOT primarily price-sensitive on commission — they are _quality-sensitive_. The decision to use White Caves is driven by:

1. Trust in agent's DAMAC Hills 2 knowledge
2. Confidence in compliance/legal protection
3. WhatsApp responsiveness (immediate availability)
4. Portal quality (can they self-serve?)

Commission discounting should be a last resort, used only when: (a) deal is ≥ AED 5M (discount 0.25%), or (b) repeat client / referral source (0.25% loyalty discount).

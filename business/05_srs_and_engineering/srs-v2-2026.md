## 1. Introduction

### 1.1 Purpose

This SRS v2.0 extends and supersedes the original SRS (WC-SRS-001, March 2026). It incorporates all Phase 1 completions, Phase 2 Landlord/Tenant Portal requirements, Phase 3 Full CRM superuser requirements, and Phase 4–10 planned features as of April 2026.

**Primary audiences:**

- Development engineers implementing Phases 2–10
- QA engineers writing portal and CRM test suites
- Business stakeholders reviewing scope and acceptance criteria
- Regulatory bodies auditing compliance capabilities
- Third-party integrators (Bayut, PropertyFinder, Meta/WhatsApp, Stripe)

### 1.2 Scope

The White Caves CRM Platform is a full-stack cloud-based web application for White Caves Real Estate LLC (Dubai, UAE) providing:

**Phase 1 (Complete ✅):**

- Public homepage with property showcase, SEO, hero, testimonials
- Authentication infrastructure (JWT, bcrypt, Firebase OAuth)
- RBAC foundation (29 roles, permissions middleware)
- Core CRM shell (UnifiedDashboardPage, dual sidebar)

**Phase 2 (In Progress 🚧):**

- Landlord Self-Service Portal (rental yield, lease management, maintenance)
- Tenant Self-Service Portal (Ejari, payments, maintenance requests)
- Backend stub completion (contracts, appointments, payments, valuations)

**Phase 3 (Planned):**

- Full CRM for `arslanmalikgoraha@gmail.com` (managing_director role)
- All 8+ CRM tabs with real API data
- AI Assistant Hub with all 40 assistants active

**Phases 4–10 (Roadmap):**

- Phase 4: WhatsApp CRM v2 (Meta API, multi-agent inbox)
- Phase 5: Compliance Management (RERA, DLD, Ejari, KYC/AML)
- Phase 6: Arabic i18n + RTL layout
- Phase 7: Data & AI (property recommendations, market forecasting)
- Phase 8: Off-plan project microsites + portal syndication
- Phase 9: Multi-User RBAC (all 29 roles, team onboarding)
- Phase 10: Progressive Web App (offline, push notifications)

**Out of Scope (this version):**

- Native iOS/Android mobile applications
- On-premises deployment
- Multi-company / multi-tenancy
- IoT sensor integration

## 2. Overall Description

### 2.1 Product Perspective

White Caves CRM Platform is a standalone cloud-based system integrating with:

```
┌──────────────────────────────────────────────────────────────────┐
│                    WHITE CAVES CRM PLATFORM                      │
│         (React SPA + Express API + MongoDB Atlas)                │
│              Cloud hosted — UAE data residency                   │
└──────────────────┬───────────────────────────────────────────────┘
                   │ External Integrations
    ┌──────────────┼────────────────────────────────┐
    │              │                │               │
    ▼              ▼                ▼               ▼
WhatsApp      PropertyFinder    Bayut API      Firebase Auth
Cloud API     Feed API          Lead Feed      (OAuth SSO)
(Meta)        (Phase 8)         (Phase 8)
    │
    ├── Stripe (Payments — Phase 2)
    ├── SendGrid (Email)
    └── Exchange Rate API (FX)
```

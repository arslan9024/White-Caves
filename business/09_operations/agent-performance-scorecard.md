## 1. Performance Philosophy

White Caves measures performance on **what matters for the client** — not just transaction volume. A great agent:
- Responds fast (client experience)
- Qualifies well (not just quantity)
- Complies fully (regulatory trust)
- Maintains accurate CRM data (team efficiency)
- Closes with integrity (reputation)

## 3. Scoring Methodology

### 3.1 Score Calculation

Each KPI is scored 1–3:
- Bronze threshold met: 1 point
- Silver threshold met: 2 points
- Gold threshold met: 3 points
- Below Bronze: 0 points

**Overall Score = SUM(KPI score × weight) / MAX possible score × 100**

### 3.2 Performance Bands

| Band | Score Range | Status |
|------|------------|--------|
| Exceeds Expectations | 85–100% | Bonus eligible |
| Meets Expectations | 65–84% | Satisfactory |
| Developing | 45–64% | Performance improvement plan |
| Below Expectations | < 45% | Formal review required |

## 4. Performance Review Process

### 4.1 Monthly Review (informal)

```
End of each month:
1. KPI dashboard updated from CRM data
2. Agent reviews own scorecard in CRM (Phase 3)
3. Manager reviews team scorecards
4. Flag: any agent in "Developing" band → 1:1 this week
5. Recognition: Gold performers → shout-out in team meeting
```

### 4.2 Quarterly Formal Appraisal

```
Week 1 of new quarter:
1. Agent self-assessment form submitted via CRM
2. Manager prepares appraisal report (KPI data + qualitative feedback)
3. 1-hour appraisal meeting:
   ├── Review last quarter performance
   ├── Celebrate achievements
   ├── Identify development areas
   └── Set goals for next quarter
4. Signed appraisal stored in HR records
5. Bonus calculation if eligible
```

### 4.3 Performance Improvement Plan (PIP)

```
Triggered when: Agent in "Developing" band for 2 consecutive months
Duration: 30 days

Contents:
1. Clear statement of performance gap
2. Specific improvement targets (e.g., "Response time < 2h by end of PIP")
3. Support offered (coaching, training, tools)
4. Review date (30 days)

Outcome:
├── Targets met → Normal review cycle resumes
└── Targets not met → Escalation to HR → potential contract review
```

## 5. RERA Compliance KPI (Mandatory — Zero Tolerance)

Any agent failing RERA compliance KPIs is automatically:
- Placed on mandatory compliance training
- Removed from lead assignment until training completed
- Subject to formal disciplinary process if repeat violation

**No exceptions for RERA violations — regulatory risk to company license.**

## 6. CRM Data Quality Score

High-quality CRM data is the foundation of AI performance. Low data quality degrades:
- Lead scoring accuracy
- Reporting accuracy
- Commission calculations
- Compliance records

**Data Quality Checklist per Lead:**
- ☐ Full name
- ☐ Valid email
- ☐ UAE phone number
- ☐ Budget range
- ☐ Property type preference
- ☐ Area preference
- ☐ Source recorded
- ☐ First contact activity logged within 24h
- ☐ Current status accurate

**Score = % of active leads with all 9 fields complete**

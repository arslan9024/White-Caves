### Design Token System Architecture

```

├─ Border colors (standard, light, input, dark)
├─ Shadow colors (soft, medium, strong, colored)
└─ Gradients (8 department colors + specialized gradients)

├─ theme.css → Imports color-palette.css

├─ design-system.css → Imports color-palette.css
├─ reset.css → Imports color-palette.css

└─ crm-standard-utilities.css → Imports color-palette.css

All CRM Modules Import:
├─ dashboard-base.css (via @import)
├─ crm-base.css (via @import)
└─ Local colors → 430+ replacements with CSS variables
```

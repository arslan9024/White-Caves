# Planning Documents — Definition of Done

**Last Updated:** 2026-05-11

A planning document is complete only when all checks are satisfied.

## Clarity

- [ ] Objective is explicit and measurable
- [ ] Scope in/out is clear
- [ ] Terms and statuses are unambiguous

## Traceability

- [ ] Tasks map to module/business docs
- [ ] Tasks map to API/UI surfaces
- [ ] Tasks map to test/acceptance artifacts

## Execution Readiness

- [ ] Deliverables are concrete and file-linked
- [ ] Dependencies and risks are listed
- [ ] Owners are named
- [ ] Validation gates are listed

## Consistency

- [ ] Status aligns with `plans/MASTER_PLAN.md`
- [ ] Status aligns with `plans/PENDING_TASKS_ONLY.md`
- [ ] Tracker pointers are present and correct

## Hygiene

- [ ] Last-updated field is current
- [ ] No broken internal links
- [ ] Superseded duplicates archived

### **Prompt for Replit Agent: UI/Frontend Implementation**

**Project:** White Caves Real Estate AI Platform - Frontend Implementation  
**Based on:** SRS Document v3.0 (Jan 12, 2024)  
**Primary Goal:** Build a unified, responsive React frontend for 32 AI Assistant dashboards with a foundational Organizational Knowledge Base.  
**Stack:** MERN (MongoDB, Express.js, React, Node.js), Redux for state, Ant Design/MUI for components.

---

### **Core Implementation Instructions:**

**1. PHASE 1: FOUNDATION (Week 1-3)**
*   **Task 1.1: Unified Navigation & Layout System**
    *   Implement `UI-FR-001`. Create a fixed top bar with Logo, Global Search, Theme Toggle, Notifications, User Profile.
    *   Build a collapsible sidebar (280px expanded / 72px collapsed) with a hierarchical menu that dynamically loads based on `user.role`.
    *   Ensure the layout is the root wrapper for every page/view.
*   **Task 1.2: Real-Time Data & State Management**
    *   Set up Redux or Context API to connect to backend APIs.
    *   Create reusable React components for: `DataLoadingSkeleton`, `EmptyStatePrompt`, `ErrorStateWithRetry`. Each must display data source, timestamp, and confidence indicators per `UI-FR-003`.
*   **Task 1.3: Role-Based Access Control (RBAC) UI**
    *   Implement `UI-FR-002` and `CRM-FR-001`. The view for the email `arslanmalikgoraha@gmail.com` must show **all navigation items**.
    *   For all other users, implement logic to show only authorized dashboard sets. Render an "Access Denied - Company Owners Only" component for unauthorized CRM access attempts.
*   **Task 1.4: Component Library Foundation**
    *   Build core reusable components: `PrimaryButton`, `SecondaryButton` (with all states: hover, active, loading, disabled), `DataTable` (with sorting/filtering), `KpiCard`, `StatusBadge`.
    *   Apply a consistent spacing scale (e.g., 4px base unit) and color palette from the brand.

**2. PHASE 2: CORE CRM & ORGANIZATIONAL INTELLIGENCE (Week 4-6)**
*   **Task 2.1: Company Owner Exclusive CRM**
    *   Build the **7-Stage Lead Pipeline** (`CRM-FR-002`) as a drag-and-drop Kanban board (use library like `@dnd-kit`).
    *   Create a `LeadScoringPanel` that visually breaks down the score per `CRM-FR-003` criteria.
    *   Implement the `AgentAssignmentEngine` visualization showing why a lead was assigned to a specific agent.
*   **Task 2.2: Organizational Knowledge Base UI**
    *   **Zoe's Dashboard Tab (`KNOW-FR-004`)**: Create an "Organizational Intelligence" tab. Build an interactive org chart (use `react-organizational-chart`) and a searchable team directory.
    *   **AI Assistants Registry (`KNOW-FR-002`)**: Build a grid view of all 32 assistants. Each card must show: assistant name, department, status indicator (`active`, `error`), and a direct link to its dashboard. Include a global search/filter by department.
    *   **Department Pages (`KNOW-FR-001`)**: Create a template page for each department to display its team members, KPIs, and linked AI assistants.
*   **Task 2.3: Knowledge Update Workflow**
    *   Build forms for Department Heads to update their team info. Implement a simple approval flow UI (e.g., "Submit for Review" button that triggers a notification to the Company Owner).

**3. PHASE 3: AI ASSISTANT DASHBOARD ROLLOUT (Week 7-9)**
*   **Task 3.1: Dashboard Template Creation**
    *   Create 3 dashboard layout templates as reusable page wrappers:
        1.  **Overview Dashboard**: For metrics-heavy views (Zoe, Theodora).
        2.  **Pipeline Dashboard**: For Kanban/process views (Clara, Sophia).
        3.  **Control Panel Dashboard**: For monitoring/status views (Aurora, Sentinel).
*   **Task 3.2: Implement High-Priority Assistant UIs**
    *   **Zoe (`AI-FR-001`)**: Build all 6 tabs. The "AI Suggestions Inbox" should aggregate cards from other assistants.
    *   **Clara (`AI-FR-005`)**: Ensure the Lead Pipeline tab is the Kanban board from Task 2.1. Add an "Activity Timeline" sidebar.
    *   **Linda (`AI-FR-008`)**: Build a split-panel view mimicking WhatsApp Web. Left: conversations list. Right: chat interface with quick template buttons.
    *   **Aurora (`AI-FR-019`)**: Create a system health panel with status cards for each service (MongoDB, APIs, etc.), using color codes (green/red/yellow).
*   **Task 3.3: Services Knowledge Graph (`KNOW-FR-003`)**
    *   Build a visual, interactive flowchart (use `react-flow`) for key services like "Luxury Villa Purchase," showing each step, responsible department, and AI assistant.

**4. PHASE 4: POLISH & LAUNCH PREP (Week 10-12)**
*   **Task 4.1: Action Feedback & Polish (`UI-FR-004`)**
    *   Apply consistent interactive states to ALL buttons and inputs. Implement a global toast notification system.
    *   Add "Undo" functionality for critical actions (e.g., deleting a lead) using a temporary state snapshot.
*   **Task 4.2: Mobile & Tablet Responsiveness**
    *   Make the collapsible sidebar auto-hide on mobile, transform into a bottom navigation bar if needed.
    *   Ensure data tables stack vertically and Kanban boards scroll horizontally on small screens.
*   **Task 4.3: Performance**
    *   Implement code-splitting so each AI Assistant's dashboard loads only its necessary code.
    *   Optimize images and ensure Lighthouse performance score >85.

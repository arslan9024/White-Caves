```yaml

  timestamp: "2026-05-21T14:30Z"
  source_module: "Module 1: Leasing"
  destinations: ["Module 3: Scheduling", "Module 2: Compliance"]

  FEEDS:
    - target: "Module 3"

      due: "2026-05-21T16:00Z"

  CAPACITY_UTILIZATION:

    available_buffer: "13%"
```

```plaintext
  Margaret runs `npm run orchestrator:blockers:brief` to unblock

15:30-17:00 | LATE AFTERNOON: Final sprint
  Teams finalize deliverables for day
  Execute all FEEDS_ACK confirmations
  Update STATUS in git

17:00-17:30 | EOD HANDOFF
```

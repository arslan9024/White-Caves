## **3. SPECIFIC REQUIREMENTS** *(UPDATED)*

### **3.1 Functional Requirements** *(ENHANCED)*

#### **3.1.1 Service Management Requirements**

**SVC-FR-001: Service Catalog Integration** *(NEW)*
The system shall maintain a complete catalog of 40+ services across 8 categories:
1. **Luxury Property Transactions (LPT)**: 5 services for high-value property sales
2. **Premium Leasing Services (PLS)**: 5 services for luxury rentals
3. **Property & Portfolio Management (PPM)**: 5 services for ongoing management
4. **Investment Advisory (IA)**: 5 services for investment strategy
5. **Legal & Compliance Services (LCS)**: 5 services for regulatory compliance
6. **Financial Services (FS)**: 5 services for financial products
7. **Value-Added Services (VAS)**: 5 services for enhanced experiences
8. **Technology Services (TS)**: 5 services for digital products
*Priority: P0 (Critical)*

**SVC-FR-002: Service Access Control** *(NEW)*
The system shall enforce service-level access controls based on:
1. **User Type**: 6 main user types with 25+ sub-categories
2. **Tier Level**: 5-tier access model (Basic, Essential, Premium, Ultra-Premium, Corporate)
3. **Verification Status**: UAE PASS verification requirement per service
4. **Transaction History**: Minimum transaction thresholds for premium services
5. **Department Role**: Internal staff access based on department and seniority
*Priority: P0 (Critical)*

**SVC-FR-003: Service Package Management** *(NEW)*
The system shall support pre-defined service packages:
1. **First-Time Buyer Essentials**: LPT-002, LCS-001, LCS-002, LCS-004, FS-001, VAS-003
2. **Landlord Pro Max**: PLS-002, PPM-001, PPM-002, LCS-002, LCS-005, FS-004
3. **UHNWI Portfolio Management**: LPT-001, PPM-003, IA-001, IA-002, FS-002, TS-002, VAS-004, TS-001
4. **Corporate Relocation Solutions**: PLS-003, VAS-003, PPM-002, TS-004, LCS-001
5. **Developer Partnership Program**: LPT-004, LPT-005, VAS-002, TS-003, TS-004, IA-003
*Priority: P1 (High)*

#### **3.1.2 Tiered Access Requirements** *(NEW)*

**TIER-FR-001: Tier Management System**
The system shall implement a 5-tier access model:
1. **Tier 1: Basic (Free)**: Property browsing, mortgage calculator, market insights
2. **Tier 2: Essential (Client)**: UAE PASS verification, transaction tracking, document upload
3. **Tier 3: Premium (VIP)**: Dedicated manager, priority access, investment advisory (min AED 5M history)
4. **Tier 4: Ultra-Premium (UHNWI)**: 24/7 concierge, full AI platform, portfolio dashboard (min AED 50M portfolio)
5. **Tier 5: Corporate/Institutional**: Custom features, API integration, bulk tools
*Priority: P0 (Critical)*

**TIER-FR-002: Automatic Tier Upgrades**
The system shall automatically upgrade client tiers based on:
1. **Transaction Value**: Cumulative transaction history
2. **Portfolio Size**: Total property portfolio value
3. **Service Usage**: Utilization of premium services
4. **Relationship Duration**: Length of client relationship
5. **Payment History**: Timely payment of fees and commissions
*Priority: P1 (High)*

#### **3.1.3 Revenue Management Requirements** *(NEW)*

**REV-FR-001: Commission & Fee Management**
The system shall track and manage all revenue streams:
1. **Sales Commissions**: 1.5-3% of property value based on service
2. **Management Fees**: 4-8% of monthly rent for property management
3. **Service Fees**: Fixed fees for legal, financial, value-added services
4. **Subscription Fees**: Monthly/annual fees for technology services
5. **Package Pricing**: Bundled pricing for service packages
*Priority: P1 (High)*

**REV-FR-002: Revenue Allocation**
The system shall allocate revenue by user type:
1. **Buyers**: 45% of total revenue
2. **Sellers**: 25% of total revenue
3. **Landlords**: 15% of total revenue
4. **Tenants**: 5% of total revenue
5. **Developers**: 8% of total revenue
6. **Corporate Clients**: 2% of total revenue
*Priority: P2 (Medium)*

### **3.4 Data Requirements** *(ENHANCED)*

#### **3.4.1 Enhanced Data Models** *(UPDATED)*

**Service Model:**
```javascript
{
  service_id: String,
  service_code: String, // e.g., "LPT-001"
  service_name: String,
  category: { type: String, enum: ['LPT', 'PLS', 'PPM', 'IA', 'LCS', 'FS', 'VAS', 'TS'] },
  description: String,
  target_market: [String],
  fees: {
    commission_rate: Number, // Percentage
    fixed_fee: Number, // AED amount
    minimum_fee: Number,
    maximum_fee: Number,
    payment_structure: String // e.g., "percentage_of_value", "fixed_monthly", "one_time"
  },
  uae_pass_required: Boolean,
  minimum_tier: { type: String, enum: ['basic', 'essential', 'premium', 'ultra_premium', 'corporate'] },
  eligible_user_types: [String], // User type IDs
  ai_assistants: [String], // AI assistants involved in delivery
  metrics: {
    target_conversion_rate: Number,
    average_deal_size: Number,
    client_retention: Number,
    profit_margin: Number
  }
}
```

**User Tier Model:**
```javascript
{
  user_id: String,
  current_tier: { type: String, enum: ['basic', 'essential', 'premium', 'ultra_premium', 'corporate'] },
  tier_history: [{
    tier: String,
    start_date: Date,
    end_date: Date,
    upgraded_by: String, // 'system' or 'manual'
    upgrade_reason: String
  }],
  tier_qualifications: {
    total_transaction_value: Number,
    portfolio_value: Number,
    service_usage_count: Number,
    relationship_duration_days: Number,
    payment_score: Number // 0-100
  },
  accessible_services: [{
    service_id: String,
    access_level: { type: String, enum: ['full', 'assisted', 'restricted', 'not_applicable'] },
    last_accessed: Date,
    usage_count: Number
  }]
}
```

**Service Package Model:**
```javascript
{
  package_id: String,
  package_name: String, // e.g., "First-Time Buyer Essentials"
  description: String,
  target_user_type: String,
  services: [{
    service_id: String,
    service_code: String,
    inclusion_type: { type: String, enum: ['full', 'discounted', 'limited'] },
    discount_percentage: Number
  }],
  pricing: {
    base_price: Number,
    commission_structure: String,
    payment_terms: String,
    cancellation_policy: String
  },
  activation_workflow: [{
    step_number: Number,
    step_name: String,
    responsible_party: String, // 'client', 'agent', 'ai_assistant', 'system'
    uae_pass_required: Boolean,
    estimated_duration_hours: Number
  }]
}
```

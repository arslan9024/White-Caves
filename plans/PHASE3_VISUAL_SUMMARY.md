## 💾 DATABASE DESIGN

```
╔═══════════════════════════════════════════════════════════════╗
║  4 MONGODB COLLECTIONS                                         ║
╚═══════════════════════════════════════════════════════════════╝

whatsapp_sessions
  ├─ sessionId (unique)       ← Device linking data
  ├─ accountId (index)        ← Account reference
  ├─ status (index)           ← Linking state
  ├─ expiresAt (TTL)          ← Auto-cleanup
  └─ Full auth flow data

whatsapp_counters
  ├─ accountId (unique)       ← Per-account
  ├─ daily counters          ← Date-based
  ├─ weekly counters         ← Week summaries
  ├─ monthly counters        ← Month trends
  └─ Segment breakdown

conversations
  ├─ conversationId (index)   ← Unique ID
  ├─ accountId (index)        ← Account ref
  ├─ recipientPhone (index)   ← Phone ref
  ├─ lastMessageTime (index)  ← Sorting
  └─ Metadata & stats

messages
  ├─ conversationId (index)   ← Conversation ref
  ├─ accountId (index)        ← Account ref
  ├─ timestamp (index)        ← Time sorting
  ├─ body (text index)        ← Full-text search
  └─ Complete message data
```

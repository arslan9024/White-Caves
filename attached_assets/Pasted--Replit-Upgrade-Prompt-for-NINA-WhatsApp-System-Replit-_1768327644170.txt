## 🚀 **Deployment Instructions for Replit**

```bash
# 1. Clone/Update NINA project
git clone https://github.com/your-org/NINA-WhatsApp.git
# or update existing Replit project

# 2. Install new dependencies
npm install

# 3. Configure environment variables
# Copy .env.example to .env and fill values
cp .env.example .env

# 4. Set up Google Sheets API
# - Enable Google Sheets API
# - Download credentials.json to project root
# - Share your Google Sheets with the service account

# 5. Configure Hugging Face (optional)
# - Get HF token from huggingface.co/settings/tokens
# - Add to .env as HF_TOKEN

# 6. Initialize database (if any)
node scripts/init-database.js

# 7. Start the system
npm start

# 8. Access dashboard
# Open Replit browser preview or use provided URL
```

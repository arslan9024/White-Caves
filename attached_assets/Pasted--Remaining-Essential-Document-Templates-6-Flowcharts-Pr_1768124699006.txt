**Process Details:**
```
Step 1: Agent lists property (manual)
Step 2: System performs auto-valuation (AI)
  - Input: Property characteristics, location, market data
  - Model: Valuation Model v2.1.4
  - Output: Estimated value with confidence score
Step 3: Generate Comparative Market Analysis (AI)
  - Find 5-10 comparable properties
  - Adjust for differences (size, condition, location)
  - Generate PDF report
Step 4: AI photo analysis (computer vision)
  - Object detection (pool, garage, garden)
  - Quality scoring
  - Feature extraction
Step 5: Publish to multiple channels
  - MLS via API
  - Internal platform
  - Partner websites
Step 6: Notify matching clients (real-time)
  - Find clients with matching preferences
  - Send personalized notifications
```

**AI Matching Logic:**
```python
def match_properties_to_client(client, properties, top_n=10):
    # 1. Get client embedding
    client_embedding = get_client_embedding(client)
    
    # 2. Get property embeddings
    property_embeddings = get_property_embeddings(properties)
    
    # 3. Calculate similarities
    similarities = cosine_similarity(
        client_embedding.reshape(1, -1),
        property_embeddings
    )[0]
    
    # 4. Apply business rules
    filtered_indices = apply_business_rules(properties, client)
    
    # 5. Combine scores
    final_scores = combine_scores(
        similarities,
        client.explicit_preferences,
        market_factors
    )
    
    # 6. Return top matches with explanations
    return get_top_matches(properties, final_scores, top_n)
```

### 5.2 Data Pipeline Error Recovery
```
ERROR SCENARIOS & RECOVERY:

Scenario 1: MLS API Unavailable
  Detection: 3 consecutive failures
  Recovery:
    1. Use cached data (last 24 hours)
    2. Queue requests for retry
    3. Exponential backoff (1min, 5min, 15min)
    4. Alert if down > 1 hour

Scenario 2: Data Quality Issues
  Detection: Validation failures > 5%
  Recovery:
    1. Quarantine bad records
    2. Attempt data cleaning
    3. Flag for manual review
    4. Update validation rules

Scenario 3: Model Performance Degradation
  Detection: Accuracy drop > 5%
  Recovery:
    1. Switch to previous model version
    2. Investigate data drift
    3. Trigger emergency retraining
    4. Notify data science team
```

```
Cache Hierarchy:
  L1: In-memory (Redis) - Milliseconds
    • User sessions
    • Frequent queries
    • API rate limits
  
  L2: CDN (CloudFront) - Seconds
    • Static assets
    • Property images
    • CSS/JS files
  
  L3: Database caching - Minutes
    • Query results
    • Aggregated data
    • ML predictions

Cache Invalidation Triggers:
```

## 4. CI/CD Pipeline

### 4.1 GitHub Actions Workflow
```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

env:
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Run unit tests
      run: npm test
      
    - name: Run integration tests
      run: npm run test:integration
      
    - name: Security scan
      uses: aquasecurity/trivy-action@master
      with:
        image-ref: 'docker.io/${{ env.IMAGE_NAME }}:latest'
        format: 'sarif'
        output: 'trivy-results.sarif'

  build-and-push:
    needs: test
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Login to Container Registry
      uses: docker/login-action@v2
      with:
        registry: ${{ env.REGISTRY }}
        username: ${{ github.actor }}
        password: ${{ secrets.GITHUB_TOKEN }}
    
    - name: Extract metadata
      id: meta
      uses: docker/metadata-action@v4
      with:
        images: ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}
    
    - name: Build and push
      uses: docker/build-push-action@v4
      with:
        context: .
        push: true
        tags: ${{ steps.meta.outputs.tags }}
        labels: ${{ steps.meta.outputs.labels }}

  deploy:
    needs: build-and-push
    runs-on: ubuntu-latest
    environment: production
    steps:
    - name: Configure AWS credentials
```

```
    3. Check logs for errors
    4. Scale up if under load

Level 2: Database Failure
  Time to recover: < 15 minutes
  Procedure:
    1. Failover to read replica
    2. Restore from latest snapshot
    3. Update connection strings
    4. Verify data integrity

Level 3: Region Failure
  Time to recover: < 1 hour

    4. Notify users of degraded service
```

```python
class PropertyValuationService:
    """
    Core service for property valuation using ML models
    """
    
    def __init__(self, model_registry: ModelRegistry, feature_store: FeatureStore):
        self.model_registry = model_registry
        self.feature_store = feature_store
        self.cache = RedisCache()
    
    async def valuate(self, property_id: UUID, valuation_type: ValuationType) -> ValuationResult:
        """
        Main valuation method
        """
        # 1. Get property data
        property_data = await self._get_property_data(property_id)
        
        # 2. Extract features
        features = await self._extract_features(property_data)
        
        # 3. Get model prediction
        model = self.model_registry.get_model("valuation_v2")
        prediction = await model.predict(features)
        
        # 4. Find comparables
        comparables = await self._find_comparables(property_data)
        
        # 5. Generate report
        report = await self._generate_report(prediction, comparables)
        
        # 6. Cache result
        await self.cache.set(f"valuation:{property_id}", report, ttl=3600)
        
        return ValuationResult(
            property_id=property_id,
            estimated_value=prediction.value,
            confidence=prediction.confidence,
            comparables=comparables,
            report=report,
            generated_at=datetime.utcnow()
        )
    
    async def _extract_features(self, property_data: PropertyData) -> FeatureVector:
        """
        Extract ML features from property data
        """
        features = FeatureVector()
        
        # Basic features
        features.add("log_sqft", math.log(property_data.square_feet))
        features.add("age", CURRENT_YEAR - property_data.year_built)
        features.add("rooms", property_data.bedrooms + property_data.bathrooms)
        
        # Location features
        location_features = await self.feature_store.get_location_features(
            property_data.latitude,
            property_data.longitude
        )
        features.merge(location_features)
        
        # Market features
        market_features = await self.feature_store.get_market_features(
            property_data.zip_code,
            datetime.utcnow()
        )
        features.merge(market_features)
        
        return features.normalize()
    
    async def _find_comparables(self, property_data: PropertyData, limit: int = 5) -> List[ComparableProperty]:
        """
        Find comparable properties using vector similarity search
        """
        # Get property embedding
        embedding = await self._get_property_embedding(property_data)
        
        # Search in vector database
        results = await self.vector_db.search(
            vector=embedding,
            filter={
                "property_type": property_data.property_type,
                "status": "sold",
                "sold_date": {"$gte": datetime.utcnow() - timedelta(days=180)}
            },
            top_k=20,
            include_metadata=True
        )
        
        # Apply business rules
        filtered = self._apply_comparable_rules(results, property_data)
        
        # Return top N
        return filtered[:limit]
    
    def _apply_comparable_rules(self, candidates: List, target: PropertyData) -> List[ComparableProperty]:
        """
        Apply business rules to filter comparable properties
        """
        comparables = []
        
        for candidate in candidates:
            # Rule 1: Distance
            distance = haversine(
                (target.latitude, target.longitude),
                (candidate.latitude, candidate.longitude)
            )
            if distance > 1.0:  # 1 mile
                continue
            
            # Rule 2: Size similarity
            size_ratio = candidate.square_feet / target.square_feet
            if size_ratio < 0.8 or size_ratio > 1.2:
                continue
            
            # Rule 3: Bedroom similarity
            if abs(candidate.bedrooms - target.bedrooms) > 1:
                continue
            
            # Rule 4: Recency
            days_old = (datetime.utcnow() - candidate.sold_date).days
            if days_old > 180:
                continue
            
            # Calculate adjustment factors
            adjustment = self._calculate_adjustment(candidate, target)
            
            comparables.append(ComparableProperty(
                property_id=candidate.id,
                address=candidate.address,
                sale_price=candidate.sale_price,
                sale_date=candidate.sold_date,
                square_feet=candidate.square_feet,
                bedrooms=candidate.bedrooms,
                bathrooms=candidate.bathrooms,
                distance_miles=distance,
                adjustment_factor=adjustment,
                adjusted_price=candidate.sale_price * adjustment
            ))
        
        # Sort by similarity score
        comparables.sort(key=lambda x: (
            abs(x.adjustment_factor - 1.0),  # Closer to 1 is better
            x.distance_miles,
            abs(x.square_feet - target.square_feet) / target.square_feet
        ))
        
        return comparables
```

### 3.2 Matching Service Design

#### 3.2.1 Architecture
```python
class MatchingService:
    """
    AI-powered property matching service
    Uses collaborative filtering + content-based matching
    """
    
    def __init__(self):
        self.user_profiles = UserProfileStore()
        self.property_embeddings = PropertyEmbeddingStore()
        self.interaction_history = InteractionHistory()
        self.recommendation_engine = RecommendationEngine()
    
    async def get_matches(
        self,
        user_id: UUID,
        filters: Optional[PropertyFilters] = None,
        limit: int = 10
    ) -> List[PropertyMatch]:
        """
        Get property matches for a user
        """
        # 1. Get user profile and preferences
        user_profile = await self.user_profiles.get(user_id)
        
        # 2. Get candidate properties based on filters
        candidates = await self._get_candidate_properties(filters)
        
        # 3. Calculate match scores using multiple strategies
        collaborative_scores = await self._collaborative_filtering(user_id, candidates)
        content_scores = await self._content_based_matching(user_profile, candidates)
        hybrid_scores = self._hybrid_scoring(collaborative_scores, content_scores)
        
        # 4. Apply business rules and diversity
        filtered = self._apply_business_rules(candidates, hybrid_scores, user_profile)
        diversified = self._diversify_recommendations(filtered, user_profile)
        
        # 5. Generate explanations
        results = await self._generate_explanations(diversified[:limit], user_profile)
        
        return results
    
    async def _collaborative_filtering(
        self,
        user_id: UUID,
        candidates: List[Property]
    ) -> Dict[UUID, float]:
        """
        Collaborative filtering based on similar users
        """
        # Find similar users
        similar_users = await self._find_similar_users(user_id)
        
        # Get properties liked by similar users
        liked_properties = await self._get_liked_properties(similar_users)
        
        # Calculate scores
        scores = {}
        for property in candidates:
            if property.id in liked_properties:
                # Calculate weighted score based on user similarity
                total_similarity = sum(
                    similarity * weight
                    for user, similarity in similar_users.items()
                    if property.id in liked_properties.get(user, [])
                )
                scores[property.id] = total_similarity
        
        return scores
    
    async def _content_based_matching(
        self,
        user_profile: UserProfile,
        candidates: List[Property]
    ) -> Dict[UUID, float]:
        """
        Content-based matching using property embeddings
        """
        # Get user preference vector
        user_vector = user_profile.preference_vector
        
        # Calculate cosine similarity with each property
        scores = {}
        for property in candidates:
            property_vector = await self.property_embeddings.get(property.id)
            similarity = cosine_similarity(user_vector, property_vector)
            
            # Boost score for explicit preferences
            if self._matches_explicit_preferences(property, user_profile):
                similarity *= 1.2
            
            scores[property.id] = similarity
        
        return scores
    
    def _hybrid_scoring(
        self,
        collaborative_scores: Dict[UUID, float],
        content_scores: Dict[UUID, float]
    ) -> Dict[UUID, float]:
        """
        Combine collaborative and content-based scores
        """
        hybrid_scores = {}
        
        for property_id in set(collaborative_scores.keys()) | set(content_scores.keys()):
            collaborative = collaborative_scores.get(property_id, 0)
            content = content_scores.get(property_id, 0)
            
            # Weighted combination
            # More weight to content-based for new users
            # More weight to collaborative for established users
            weight_collaborative = 0.6  # Can be dynamic based on user history
            weight_content = 0.4
            
            hybrid_score = (collaborative * weight_collaborative + 
                          content * weight_content)
            
            hybrid_scores[property_id] = hybrid_score
        
        return hybrid_scores
    
    def _apply_business_rules(
        self,
        candidates: List[Property],
        scores: Dict[UUID, float],
        user_profile: UserProfile
    ) -> List[Tuple[Property, float]]:
        """
        Apply business rules to filter recommendations
        """
        filtered = []
        
        for property in candidates:
            score = scores.get(property.id, 0)
            
            # Rule 1: Budget constraints
            if user_profile.max_budget and property.list_price > user_profile.max_budget * 1.1:
                score *= 0.5  # Penalize but don't eliminate
            
            # Rule 2: Location preferences
            if user_profile.preferred_locations:
                in_preferred = any(
                    self._in_location(property, location)
                    for location in user_profile.preferred_locations
                )
                if not in_preferred:
                    score *= 0.7
            
            # Rule 3: Property type preferences
            if (user_profile.property_types and 
                property.property_type not in user_profile.property_types):
                score *= 0.6
            
            # Rule 4: Recent listings get boost
            days_listed = (datetime.utcnow() - property.listed_date).days
            if days_listed < 7:
                score *= 1.1  # 10% boost for new listings
            
            if score > 0.1:  # Minimum threshold
                filtered.append((property, score))
        
        return filtered
    
    def _diversify_recommendations(
        self,
        candidates: List[Tuple[Property, float]],
        user_profile: UserProfile,
        diversity_factor: float = 0.3
    ) -> List[Tuple[Property, float]]:
        """
        Ensure diversity in recommendations
        """
        if not candidates:
            return []
        
        # Group by property type and neighborhood
        groups = defaultdict(list)
        for property, score in candidates:
            key = f"{property.property_type}:{property.neighborhood}"
            groups[key].append((property, score))
        
        # Select top from each group
        selected = []
        for group_items in groups.values():
            # Sort by score within group
            group_items.sort(key=lambda x: x[1], reverse=True)
            
            # Take top N from each group based on diversity factor
            take_n = max(1, int(len(group_items) * diversity_factor))
            selected.extend(group_items[:take_n])
        
        # Resort by score
        selected.sort(key=lambda x: x[1], reverse=True)
        
        return selected
```

#### 3.2.2 Matching Algorithm Details
```python
class RecommendationEngine:
    """
    Core recommendation algorithms
    """
    
    def matrix_factorization(self, interactions: np.ndarray, k: int = 50) -> Tuple[np.ndarray, np.ndarray]:
        """
        Matrix factorization for collaborative filtering
        """
        # Initialize matrices
        n_users, n_items = interactions.shape
        P = np.random.rand(n_users, k) * 0.01
        Q = np.random.rand(n_items, k) * 0.01
        
        # ALS optimization
        for iteration in range(20):
            # Fix Q, solve for P
            for i in range(n_users):
                # Get items rated by user i
                rated_items = np.where(interactions[i] > 0)[0]
                if len(rated_items) == 0:
                    continue
                
                # Solve least squares
                Q_rated = Q[rated_items]
                ratings = interactions[i, rated_items]
                P[i] = np.linalg.lstsq(Q_rated.T @ Q_rated + 0.1 * np.eye(k), 
                                      Q_rated.T @ ratings, rcond=None)[0]
            
            # Fix P, solve for Q
            for j in range(n_items):
                # Get users who rated item j
                rating_users = np.where(interactions[:, j] > 0)[0]
                if len(rating_users) == 0:
                    continue
                
                # Solve least squares
                P_rated = P[rating_users]
                ratings = interactions[rating_users, j]
                Q[j] = np.linalg.lstsq(P_rated.T @ P_rated + 0.1 * np.eye(k), 
                                      P_rated.T @ ratings, rcond=None)[0]
        
        return P, Q
    
    def calculate_similarity(self, user_vectors: np.ndarray) -> np.ndarray:
        """
        Calculate user similarity matrix
        """
        # Cosine similarity
        norms = np.linalg.norm(user_vectors, axis=1)
        normalized = user_vectors / norms[:, np.newaxis]
        similarity = normalized @ normalized.T
        
        return similarity
```

```python
class ModelServer:
    """
    TensorFlow Serving wrapper for ML models
    """
    
    def __init__(self, config: ModelServerConfig):
        self.config = config
        self.clients = {}
        self.model_registry = ModelRegistry()
        self.metrics = MetricsCollector()
        
    async def start(self):
        """Start model servers for all registered models"""

            await self._start_model_server(model_name)
    
    async def predict(self, model_name: str, inputs: Dict) -> Prediction:
        """
        Make prediction using specified model
        """
        start_time = time.time()
        
        try:
            # Get model client
            client = self.clients.get(model_name)
            if not client:
                client = await self._get_model_client(model_name)
                self.clients[model_name] = client
            
            # Prepare request
            request = self._prepare_request(inputs)
            
            # Make prediction
            response = await client.predict(request)
            
            # Process response
            prediction = self._process_response(response)
            
            # Track metrics
            latency = time.time() - start_time
            await self.metrics.track_prediction(
                model_name=model_name,
                latency=latency,
                success=True
            )
            
            return prediction
            
        except Exception as e:
            # Track error
            await self.metrics.track_prediction(
                model_name=model_name,
                latency=time.time() - start_time,
                success=False,
                error=str(e)
            )
            raise
    
    async def _start_model_server(self, model_name: str):
        """Start a TensorFlow Serving instance for a model"""
        model_path = self.model_registry.get_model_path(model_name)
        model_version = self.model_registry.get_latest_version(model_name)
        
        # Start Docker container
        container = await docker.containers.run(
            "tensorflow/serving:latest",
            command=[
                f"--model_name={model_name}",
                f"--model_base_path={model_path}",
                "--rest_api_port=8501",
                "--port=8500"
            ],
            ports={'8501/tcp': None},
            detach=True
        )
        
        # Wait for server to be ready
        await self._wait_for_server_ready(container)
        
        # Store container reference
        self.containers[model_name] = container
    
    def _prepare_request(self, inputs: Dict) -> Dict:
        """Prepare request for TensorFlow Serving"""
        # Convert inputs to format expected by model
        request = {
            "signature_name": "serving_default",
            "instances": []
        }
        
        # Handle batch and single predictions
        if isinstance(inputs, list):
            for input_dict in inputs:
                request["instances"].append(self._convert_input(input_dict))
        else:
            request["instances"].append(self._convert_input(inputs))
        
        return request
    
    def _convert_input(self, input_dict: Dict) -> Dict:
        """Convert Python types to TensorFlow serving format"""
        converted = {}
        
        for key, value in input_dict.items():
            if isinstance(value, (int, float)):
                converted[key] = [value]
            elif isinstance(value, list):
                converted[key] = value
            elif isinstance(value, np.ndarray):
                converted[key] = value.tolist()
            else:
                # Try to convert to float
                try:
                    converted[key] = [float(value)]
                except:
                    converted[key] = [value]
        
        return converted
```

```python
class SmartCache:
    """
    Intelligent caching with multiple strategies
    """
    
    def __init__(self):
        self.redis = RedisCache()
        self.local_cache = LocalCache()
        self.cache_config = self._load_cache_config()
    
    async def get(self, key: str, loader: Callable = None) -> Any:
        """
        Get value from cache, load if not present
        """
        # Try local cache first (fastest)
        value = self.local_cache.get(key)
        if value is not None:
            self._record_hit("local")
            return value
        
        # Try Redis cache
        value = await self.redis.get(key)
        if value is not None:
            # Populate local cache
            self.local_cache.set(key, value, ttl=60)
            self._record_hit("redis")
            return value
        
        # Load from source
        if loader:
            value = await loader()
            
            # Determine TTL based on key pattern
            ttl = self._determine_ttl(key)
            
            # Store in both caches
            await self.redis.set(key, value, ttl=ttl)
            self.local_cache.set(key, value, ttl=min(ttl, 60))
            
            self._record_miss()
            return value
        
        return None
    
    def _determine_ttl(self, key: str) -> int:
        """
        Determine TTL based on key pattern
        """
        patterns = {
            "property:": 3600,  # 1 hour for property data
            "valuation:": 1800,  # 30 minutes for valuations
            "user:": 300,       # 5 minutes for user data
            "search:": 60,      # 1 minute for search results
            "match:": 300,      # 5 minutes for matches
            "default": 300      # 5 minutes default
        }
        
        for pattern, ttl in patterns.items():
            if key.startswith(pattern):
                return ttl
        
        return patterns["default"]
```

```python
class QueryOptimizer:

    async def optimize_property_search(
        self,

        # Strategy 4: Apply business logic filtering

        # Strategy 5: Cache results
        await self.cache.set(cache_key, filtered, ttl=60)
        
        return filtered[:limit]
    
    def _build_optimized_query(self, filters: PropertyFilters) -> str:
        """
        Build optimized SQL query based on filters
        """

        where_clauses = []

            query_parts.append("LEFT JOIN valuations v ON v.property_id = p.id")
            where_clauses.append("v.created_at > NOW() - INTERVAL '7 days'")

        if filters.property_type:
            where_clauses.append("p.property_type = %s")
            params.append(filters.property_type)
        
        if filters.bedrooms:
            where_clauses.append("p.bedrooms >= %s")

        if where_clauses:
```

```python
class MetricsCollector:
    """
    Collect and report system metrics
    """
    
    async def track_api_request(self, request: Request, response: Response):
        """
        Track API request metrics
        """
        metrics = {
            "api_requests_total": 1,
            "api_request_duration_seconds": response.time,
            "api_request_status_code": response.status_code,
            "api_request_path": request.path,
            "api_request_method": request.method,
        }
        
        if response.status_code >= 400:
            metrics["api_errors_total"] = 1
        
        # Add user agent and other context
        metrics.update({
            "user_agent": request.headers.get("User-Agent", "unknown"),
            "user_id": getattr(request, "user_id", "anonymous"),
        })
        
        await self._send_metrics(metrics)
    
    async def track_ml_prediction(
        self,
        model_name: str,
        latency: float,
        success: bool,
        error: str = None
    ):
        """
        Track ML prediction metrics
        """
        metrics = {
            f"ml_predictions_total{{model=\"{model_name}\"}}": 1,
            f"ml_prediction_latency_seconds{{model=\"{model_name}\"}}": latency,
            f"ml_prediction_success{{model=\"{model_name}\"}}": 1 if success else 0,
        }
        
        if not success and error:
            metrics[f"ml_prediction_errors{{model=\"{model_name}\",error=\"{error}\"}}"] = 1
        
        await self._send_metrics(metrics)
    
    async def track_business_metric(self, metric_name: str, value: float, tags: Dict = None):
        """
        Track business metrics
        """
        tags = tags or {}
        tags_str = ",".join(f'{k}="{v}"' for k, v in tags.items())
        
        metrics = {
            f"{metric_name}{{{tags_str}}}": value
        }
        
        await self._send_metrics(metrics)
    
    async def _send_metrics(self, metrics: Dict[str, float]):
        """
        Send metrics to monitoring system
        """
        # Send to Prometheus
        await self.prometheus_client.send(metrics)
        
        # Send to CloudWatch
        await self.cloudwatch_client.put_metric_data(metrics)
        
        # Send to logging
        self.logger.info("Metrics collected", {"metrics": metrics})
```

```python
class TracingMiddleware:
    """
    Distributed tracing middleware
    """
    
    async def __call__(self, request, call_next):
        # Extract or generate trace context
        trace_id = request.headers.get('X-Trace-ID') or str(uuid.uuid4())
        span_id = str(uuid.uuid4())
        
        # Create root span
        with tracer.start_span("http_request", trace_id=trace_id) as span:
            span.set_attribute("http.method", request.method)
            span.set_attribute("http.url", str(request.url))
            span.set_attribute("http.route", request.url.path)
            
            # Add trace headers to request
            request.state.trace_id = trace_id
            request.state.span_id = span_id
            
            # Process request
            start_time = time.time()
            try:
                response = await call_next(request)
                duration = time.time() - start_time
                
                span.set_attribute("http.status_code", response.status_code)
                span.set_attribute("http.duration", duration)
                
                # Add trace headers to response
                response.headers["X-Trace-ID"] = trace_id
                
                return response
                
            except Exception as e:
                span.record_exception(e)
                span.set_status(StatusCode.ERROR)
                raise
```

# DUBAI_BUSINESS_STRATEGY

1. **Zero-Cost Local Mocking Rule:** Live integrations or expensive external API connection keys for Dubai Land Department (DLD), RERA sandboxes, or Ejari setups are banned for this development phase.
2. **High-Fidelity Mocks:** All data endpoints must feed off comprehensive, pre‑baked local mock data objects using standard Dubai real‑estate taxonomies (Form 7, Form 12, Ejari activations) to ensure the app is 100 % demo‑ready and runs for free on our laptop.
3. **Superuser Priority focus:** Prioritize stable state hydration for the ‘Lion’ user profile (`managing_director` role) to guarantee instant, flicker‑free dashboard load times.

## 🔐 3. Role-Based Access Control (RBAC) Security System
To prevent unprivileged modifications, security clearance is managed using 5 specific Access Levels mapped to database schema models.

+------------------------------------------------------------+

| Level 5: MASTER ADMIN (The 'Lion' Profile / EXE-001)       |
| -> Full System Override, Database Drops, Global Ledgers    |
+------------------------------------------------------------+
                             |
+------------------------------------------------------------+

| Level 4: DEPARTMENT HEAD (Executive Tiers / CSO, CFO, CTO)  |
| -> Write Configs, Approve Transfers, Export System Logs    |
+------------------------------------------------------------+
                             |
+------------------------------------------------------------+

| Level 3: POWER USER (Senior Tiers / Brokers, Architects)    |
| -> Write Data, Execute Mocks, Modify Assigned Rows        |
+------------------------------------------------------------+
                             |
+------------------------------------------------------------+

| Level 2: RESTRICTED OPERATOR (Mid & Junior Tiers)          |
| -> Read Assigned Scopes, Update Individual Tickets         |
+------------------------------------------------------------+
                             |
+------------------------------------------------------------+

| Level 1: READ FALLBACK (Intern Tiers)                      |
| -> View High-Level Dashboards, Populated Mock Arrays       |
+------------------------------------------------------------+
